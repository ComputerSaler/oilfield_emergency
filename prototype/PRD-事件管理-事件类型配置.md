## 1. 文档元数据与边界

### 1.1 需求背景

事件工作台的运转依赖一批可运营调整的配置参数：哪些事件类型可以被创建、各类型的等级判定参考标准是什么、每个等级应该触发哪些推荐响应措施、不同等级的评级时限和上报截止时间是多少、各通知节点通知谁。这些参数如果硬编码，每次业务调整都需要开发介入；做成配置页面后，安保系统管理员可以根据实际运营情况自行维护。

本模块是事件工作台的「参数中台」，所有配置变更只影响**之后**创建的事件，已存在的事件记录不受影响。

### 1.2 与既有模块的依赖关系

| 关联模块 | 关系方向 | 具体内容 |
|---|---|---|
| 事件工作台 | 本模块**被依赖** | 工作台读取本模块的全部配置，实时生效 |
| 预警规则配置 | 参考关系 | 预警类型字典中「可升级为事件类型」的映射来源于本模块的类型列表 |
| 人员管理 – 用户信息 | 本模块**读取** | 通知配置和上报负责人的「固定人员」选项来自用户列表 |
| 人员管理 – 排班管理 | 本模块**读取** | 通知配置中「今日值班」选项从排班管理推算 |

### 1.3 权限边界

| 编号 | 边界 |
|---|---|
| PB-01 | 只有具备 `incident.type.config` 权限的用户可以修改配置 |
| PB-02 | 所有配置变更记录操作日志（操作人、操作时间、变更前后的值），日志只读，不可删除 |
| PB-03 | 具备 `incident.view` 权限的用户可以**只读查看**类型配置，不可修改 |

| PB-05 | 事件类型**不支持物理删除**，只支持停用（软删除），以保护历史数据完整性 |

## 2. 核心概念

| 术语 | 精确定义 |
|---|---|
| **事件类型** | 对安防事件性质的分类标签（如「无人机威胁」「人员入侵」「设施安全」），每类事件有独立的等级分级标准和推荐响应措施 |
| **等级分级标准** | 每种事件类型对应的四级（Ⅰ–Ⅳ）文字描述，从影响范围、人员风险、所需响应资源三个维度说明各级特征，供值班员在确认等级时对照参考 |
| **推荐响应措施** | 按事件类型+等级组合预设的标准处置条目，在事件详情页概要 Tab 中展示，值班员可勾选确认为「处置计划」 |
| **停用** | 对事件类型的软删除操作。停用后该类型不出现在新建事件的类型选项中，已存在的事件记录不受影响 |

## 3. 配置变更规则

所有配置变更遵循以下规则：

1. **仅影响后续**：配置修改仅对变更时间点之后创建的事件生效，已有事件不重新计算
2. **全量操作日志**：每次保存记录变更人、时间戳、变更前后值，日志在每个 Tab 底部「操作日志」区域可查
3. **草稿模式**：每个 Tab 进入编辑状态后，修改内容在点击「保存」前不生效；「取消」恢复到修改前的状态
4. **停用保护**：停用类型前，若该类型存在进行中（非终态）的事件，系统提示「该类型下有 N 条进行中的事件，停用后不影响这些事件的处置，但不可再新建该类型事件」，需再次确认

## 5. 页面布局与各 Tab 内容

```
┌─ PageContainer ──────────────────────────────────────────────────┐
│  Tab: [类型与表单] [等级分级标准] [推荐响应措施] [时限与上报] [通知配置] │
│  ─────────────────────────────────────────────────────────────── │
│  [各 Tab 内容区域]                                                 │
```

每个 Tab 右上角有「编辑」按钮，点击进入编辑模式；底部出现「保存」「取消」按钮。未进入编辑模式时，所有字段只读。

### 5.1 Tab① — 类型与表单

**功能：** 维护事件类型字典，定义每种事件类型的基础属性。

```
┌─ 类型与表单 ──────────────────────────────────────────────────────┐
│  [+ 新增类型]                               [编辑]                │
│  ─────────────────────────────────────────────────────────────── │
│  类型名称          颜色标识   状态    操作                          │
│  无人机威胁         ● 红色    启用    [查看详情] [停用]             │
│  人员入侵           ● 橙色    启用    [查看详情] [停用]             │
│  设施安全           ● 黄色    启用    [查看详情] [停用]             │
│  车辆异常           ● 蓝色    启用    [查看详情] [停用]             │
│  其他               ● 灰色    启用    [查看详情] [停用]             │
└──────────────────────────────────────────────────────────────────┘
```

点击「查看详情」或「新增类型」展开右侧抽屉：

| 字段 | 类型 | 说明 |
|---|---|---|
| 类型名称 | 文本，必填，最多 20 字 | 如「无人机威胁」 |
| 颜色标识 | 颜色选择器，必填 | 用于列表行等级色块和地图标记 |
| 来源预警类型映射 | 多选，可选 | 哪些预警类型升级时可选择本事件类型（对应预警规则配置中的预警类型字典） |
| 备注 | 文本，选填 | 运营说明，不对外展示 |

**初始内置类型（平台预置，可编辑不可删除）：**

| 类型名称 | 颜色 | 典型来源预警类型 |
|---|---|---|
| 无人机威胁 | 红色 | 反无人机系统告警、无人机偷飞 |
| 人员入侵 | 橙色 | 围界突破、可疑人员、SOS 相关 |
| 设施安全 | 黄色 | 设备异常、围界损毁 |
| 车辆异常 | 蓝色 | 车辆越界、异常停车 |
| 其他 | 灰色 | 手工录入无法归类的情况 |

### 5.2 Tab② — 等级分级标准

**功能：** 维护各事件类型的四级分级描述，供确认等级弹窗内的「查看分级标准」浮窗使用。

```
┌─ 等级分级标准 ─────────────────────────────────────────────────────┐
│  选择事件类型: [无人机威胁 ▼]                        [编辑]         │
│  ─────────────────────────────────────────────────────────────── │
│  Ⅰ级（最严重）                                                     │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │ 影响范围：多营地同时受到威胁，或无人机已进入核心设施区域上方   │  │
│  │ 人员风险：现场人员处于直接威胁中，存在人身伤亡可能            │  │
│  │ 所需资源：需同时调动多支应急队伍，需上报集团公司              │  │
│  └────────────────────────────────────────────────────────────┘  │
│  Ⅱ级                                                              │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │ 影响范围：单一营地受影响，无人机在禁飞区内持续飞行…           │  │
│  └────────────────────────────────────────────────────────────┘  │
│  Ⅲ级  …                                                           │
│  Ⅳ级（最轻）  …                                                    │
└──────────────────────────────────────────────────────────────────┘
```

每个等级的描述字段：

| 字段 | 说明 |
|---|---|
| 影响范围描述 | 文本，描述该等级下事件波及的地理或资源范围 |
| 人员风险描述 | 文本，描述对现场人员的威胁程度 |
| 所需资源描述 | 文本，描述响应所需的资源级别（单队/多队/需上报上级） |

**平台内置初始内容（各类型的参考框架，可在平台内编辑）：**

**无人机威胁：**

| 等级 | 影响范围 | 人员风险 | 所需资源 |
|---|---|---|---|
| Ⅰ级 | 多营地受威胁，或无人机已进入核心设施区域上方，疑似携带危险物品 | 现场人员处于直接威胁中，存在人身伤亡可能 | 需同时调动多支应急队伍，需上报集团公司 |
| Ⅱ级 | 单一营地受影响，无人机在禁飞区内持续飞行，或来源不明无人机已进入营地边界内 | 潜在威胁，需立即核实 | 需调动单支应急队伍，需上报安保部 |
| Ⅲ级 | 无人机在营地外围 1km 内徘徊，暂未越界 | 潜在威胁，需持续监控 | 值班员处置，可通知安保部备案 |
| Ⅳ级 | 远程无人机活动，或已确认为己方无人机且操作异常 | 极低风险 | 值班员记录即可，无需上报 |

**人员入侵：**

| 等级 | 影响范围 | 人员风险 | 所需资源 |
|---|---|---|---|
| Ⅰ级 | 武装人员进入营地核心区域，或多点突破围界 | 现场人员面临直接威胁，存在暴力冲突可能 | 需立即启动安全疏散，上报集团公司 |
| Ⅱ级 | 不明人员突破围界进入营地 | 威胁存在，需立即处置 | 需安保队伍拦截，上报安保部 |
| Ⅲ级 | 可疑人员在围界外持续游荡，有意图进入迹象 | 低风险，需关注 | 值班员协调现场安保巡视 |
| Ⅳ级 | 偶发人员靠近围界，无持续意图 | 极低风险 | 记录并保持观察 |

**设施安全：**

| 等级 | 影响范围 | 人员风险 | 所需资源 |
|---|---|---|---|
| Ⅰ级 | 关键设施损毁或失效（如主要管道、发电设施），影响整体运营 | 存在安全事故风险 | 需紧急维修团队响应，上报集团 |
| Ⅱ级 | 重要设施异常（如监控设备、围界损毁），范围局限 | 安防盲区风险增加 | 需专业维修响应，上报安保部 |
| Ⅲ级 | 非关键设备故障，功能降级但有冗余 | 低风险 | 常规维修工单 |
| Ⅳ级 | 轻微设备告警，自动恢复可能 | 极低风险 | 记录并跟踪 |

**车辆异常：**

| 等级 | 影响范围 | 人员风险 | 所需资源 |
|---|---|---|---|
| Ⅰ级 | 车辆武力冲撞围界，或多辆车辆协同异常行为 | 存在直接人员威胁 | 需立即安保响应，上报集团 |
| Ⅱ级 | 单辆车辆越界，驾驶员身份不明 | 潜在威胁 | 需安保拦截核查 |
| Ⅲ级 | 车辆在营地附近异常停留，未越界 | 低风险 | 值班员记录，通知安保关注 |
| Ⅳ级 | 车辆GPS信号异常或超速告警，无安防威胁 | 极低风险 | 记录并通知车辆管理员 |

### 5.3 Tab③ — 推荐响应措施

**功能：** 为每种「事件类型 × 等级」组合维护推荐处置条目列表，在事件详情概要 Tab 中展示供值班员勾选。

```

│  ─────────────────────────────────────────────────────────────── │
│  以下措施将在事件详情页「推荐响应措施」区域展示，值班员可勾选为处置计划  │
│  [+ 新增措施]                                                      │
│  ─────────────────────────────────────────────────────────────── │
│  #1  立即调取预警区域最近高点摄像头画面确认目标                      │
│  #2  通知反无操作员就位，准备干扰操作                               │
│  #3  通知营地管理员限制人员进入暴露区域                              │
│  #4  调度 C 类无人机飞往预警位置进行空中取证                         │
│  #5  通知安保部门值班负责人                                         │
│      [↑][↓] 拖动排序    [删除]                                     │
└──────────────────────────────────────────────────────────────────┘
```

**字段说明：**

| 字段 | 说明 |
|---|---|
| 措施描述 | 文本，最多 100 字，描述具体处置动作 |
| 排序 | 数字，越小越靠前；支持拖动排序 |

**初始内置措施（各类型+等级组合，平台预置可编辑）：**

*（以「无人机威胁 - Ⅱ级」为示例，其他组合类似逻辑）*

1. 立即调取预警区域最近高点摄像头画面确认目标
2. 通知反无操作员就位，准备干扰操作
3. 通知营地管理员限制人员进入暴露区域
4. 调度 C 类无人机飞往预警位置进行空中取证
5. 通知安保部门值班负责人

## 1. 文档说明

### 1.1 文档目的
本文档定义"应急物资管理-物资台账"模块的功能需求、交互细节、数据结构及业务规则，作为原型设计、技术开发、测试验收的唯一依据。

### 1.2 适用范围
本模块适用于海外油田现场应急指挥平台PC端，管理应急物资的清单信息，包括物资的增删改查、定期盘点、盘点历史追溯、库存预警、导出导入等功能。

### 1.3 术语与定义

| 术语 | 定义 | 说明 |
|------|------|------|
| 物资台账 | 应急物资的清单明细 | 记录每种物资的名称、规格、数量、存放位置等基础信息 |
| 当前库存 | 物资的实时库存数量 | 通过盘点操作更新，不自动计算出入库流水 |
| 盘点 | 定期核实物资实际数量的操作 | 盘点后更新台账的当前库存，并记录盘点历史 |
| 盘点历史 | 每次盘点操作的流水记录 | 记录盘点前后数量、差异、盘点人、盘点时间等信息 |
| 库存预警 | 当前库存低于预警值时的提醒 | 通过视觉标识和筛选条件体现，不推送预警消息 |
| 支撑预案 | 该物资被哪些应急预案引用 | 由预案管理模块维护关联关系，物资台账只读展示 |

### 1.4 依赖关系

**上游依赖（输入）：**
- **存放点管理**：物资的"所属存放点"字段来源于存放点列表
- **用户信息台账**：盘点操作的"盘点人"字段来源于在职人员列表
- **预案管理**（未开发）：预案选择应急物资，建立多对多关联关系

**下游依赖（输出）：**
- **预案管理**（未开发）：预案编制时选择应急物资，引用物资台账的物资列表
- **大屏-安防态势综合驾驶舱**：点击存放点图标，显示该存放点的物资明细
- **大屏-事件感知处置驾驶舱（战时模式）**：显示物资存放点与物资信息，支持应急调度
- **应急指挥/指挥调度**：资源调度沙盘中的"物资调拨"数据来源

## 2. 功能概述

### 2.1 模块定位
物资台账是应急物资管理的核心模块，负责管理应急物资的清单信息，通过定期盘点更新库存数量，为应急预案、指挥调度、大屏展示提供物资数据支撑。

### 2.2 核心功能
1. 物资信息的增删改查
2. 单条盘点、批量盘点、按存放点盘点、导入盘点（4种盘点方式）
3. 盘点历史记录追溯
4. 库存预警（视觉标识 + 筛选条件）
5. 关联预案查看（被哪些预案引用）
6. 导出台账快照 + 盘点历史
7. 导入盘点模板

### 2.3 业务价值
- **资产清晰**：建立全面的应急物资清单，明确"有什么、在哪里、有多少"
- **动态更新**：通过灵活的盘点方式，保持库存数据的准确性
- **预警提醒**：库存不足时及时提示，避免应急时缺少关键物资
- **可追溯**：盘点历史记录支持审计与分析，了解物资消耗趋势
- **支撑决策**：为应急预案编制、资源调度提供准确的物资数据

### 2.4 核心设计理念

**简化运维，适应现场：**
- **不做出入库流水**：客户现场无人力维护详细的出入库记录
- **盘点即更新**：每次盘点直接覆盖当前库存，以盘点结果为准
- **灵活盘点**：支持4种盘点方式，覆盖零散核查、批量盘点、全面盘点、线下采集等场景
- **可选预警**：最低库存预警值可选填，不强制维护

### 3.2 筛选栏

**筛选条件（横向排列）：**

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 所属存放点 | 下拉单选 | 默认"全部"，选项来自存放点管理模块的存放点列表 |
| 物资分类 | 下拉单选 | 默认"全部"，选项来自数据字典（见3.2.1） |
| 物资名称 | 文本输入 | 支持模糊搜索（前端过滤或后端Like查询） |
| 库存状态 | 下拉单选 | 选项：全部/库存充足/库存预警/库存为零，默认"全部" |

**交互规则：**
- 筛选条件实时生效（输入框防抖300ms）
- 右侧显示"重置"按钮，一键清空所有筛选条件
- 筛选后表格分页重置为第1页

**库存状态筛选规则：**
- **库存充足**：当前库存 > 最低库存预警值，或最低库存预警值未设置
- **库存预警**：当前库存 ≤ 最低库存预警值 且 当前库存 > 0
- **库存为零**：当前库存 = 0

### 3.7 盘点功能

本模块提供4种盘点方式，覆盖不同场景的盘点需求。

---

#### 3.7.1 单条盘点

**触发方式：**
- 点击表格行的"盘点"按钮

**交互流程：**
1. 弹出盘点对话框（Modal，非抽屉）
2. 对话框显示：
   - 物资名称（只读）
   - 所属存放点（只读）
   - 当前库存：XXX（只读，显示当前值）
   - 实际数量：数字输入框（必填，≥ 0）
   - 盘点人：默认当前登录用户，下拉可修改（来自在职人员列表）
   - 备注：文本输入（可选，最多100字符）
3. 点击"确认盘点"：
   - 更新该物资的当前库存 = 实际数量
   - 生成一条盘点历史记录（盘点前数量、盘点后数量、差异、盘点人、盘点时间、备注）
   - 更新最后盘点日期、最后盘点人
   - 关闭对话框，刷新列表，弹出成功提示
4. 点击"取消"：关闭对话框，不做任何更改

---

#### 3.7.2 批量盘点

**触发方式：**
- 勾选多条物资（至少1条）→ 顶部"批量盘点"按钮变为可用 → 点击按钮

**交互流程：**
1. 打开批量盘点抽屉（宽度640px）
2. 抽屉标题："批量盘点（已选 X 项物资）"
3. 抽屉内容：
   - 统一盘点人设置（默认当前登录用户，可修改，应用于所有被盘点物资）
   - 物资盘点列表，每行显示：物资名称、所属存放点、当前库存（只读）、实际数量（输入框，≥ 0）、差异（自动计算，实时显示）
   - 底部状态栏："已填写 X/X"（显示已填实际数量的物资数 / 总物资数）
4. 实际数量输入框为空 = 跳过该物资（不盘点）
5. 底部按钮：取消、提交盘点
6. 点击"提交盘点"：
   - 只更新实际数量不为空的物资
   - 批量生成盘点历史记录
   - 关闭抽屉，刷新列表，弹出"成功盘点 X 项物资"提示

---

#### 3.7.3 按存放点盘点

**触发方式：**
- 点击顶部"按存放点盘点"按钮

**智能判断逻辑：**
- **如果筛选栏已选择某个存放点**：直接打开该存放点的盘点抽屉（跳过存放点选择步骤）
- **如果筛选栏未选择存放点（全部）**：弹出存放点选择对话框，让用户选择要盘点的存放点，确认后打开盘点抽屉

**交互流程（盘点抽屉）：**
1. 打开按存放点盘点抽屉（宽度640px）
2. 抽屉标题："按存放点盘点 - XXX（共 X 项物资）"
3. 抽屉内容：
   - 统一盘点人设置（默认当前登录用户，可修改）
   - 物资盘点列表，每行显示：物资名称、当前库存（只读）、实际数量（输入框，≥ 0）、差异（自动计算）
   - 底部状态栏："已填写 X/X"
4. 实际数量输入框为空 = 跳过该物资（允许跳过，不强制全填）
5. 底部按钮：取消、提交盘点
6. 点击"提交盘点"：
   - 只更新实际数量不为空的物资
   - 批量生成盘点历史记录
   - 关闭抽屉，刷新列表，弹出"成功盘点 X 项物资"提示

---

#### 3.7.4 导入盘点

**触发方式：**
- 点击顶部"导入盘点"按钮 → 打开导入盘点弹窗

**导入弹窗（Modal）：**
- 标题："导入盘点"
- 内容区：
  - 顶部提示文字："请先下载盘点模板，填写实际数量后再上传"
  - 操作1：下载模板按钮（"下载盘点模板"，点击下载Excel模板）
  - 操作2：上传文件区域（拖拽或点击选择文件，仅接受.xlsx/.xls格式，文件大小限制5MB）
- 底部按钮：取消、开始导入

**Excel模板字段：**

| 列名 | 是否必填 | 说明 |
|------|----------|------|
| 所属存放点名称 | 是（匹配用） | 与系统中的存放点名称完全一致 |
| 物资名称 | 是（匹配用） | 与系统中的物资名称完全一致 |
| 物资分类 | 否（仅供参考） | 只读，不用于匹配，供填写人参考 |
| 规格型号 | 否（仅供参考） | 只读，不用于匹配，供填写人参考 |
| 计量单位 | 否（仅供参考） | 只读，不用于匹配，供填写人参考 |
| 当前库存（系统值） | 只读 | 导出时的快照值，供线下盘点参考 |
| 实际数量（盘点填写） | 否 | 填写实际盘点数量，**空行跳过不更新** |
| 备注 | 否 | 本次盘点备注 |

**匹配规则：**
- 以"物资名称 + 所属存放点名称"组合作为唯一匹配键
- 完全匹配（不支持模糊匹配），名称大小写及空格须与系统一致

**导入校验（上传后预览）：**
1. 解析文件，显示预览表格
2. 校验结果分三类：
   - ✅ **有效行**：物资名称+存放点名称匹配成功，实际数量填写了有效数字
   - ⚠️ **跳过行**：实际数量为空，将跳过此物资，不更新
   - ❌ **错误行**：物资名称+存放点名称找不到对应记录；或实际数量不是有效数字（负数、非数字）
3. 若存在错误行，弹出错误详情，提示用户修改后重新上传，不允许提交
4. 若无错误行，显示"有效行X条，跳过行X条"，用户确认后执行导入
5. 导入成功后：更新对应物资的当前库存，生成盘点历史记录，关闭弹窗，刷新列表

**盘点人处理：**
- 通过导入盘点方式更新的物资，盘点人记录为当前登录用户

## 5. 业务规则

### 5.1 数据归属
- **平台自建主数据**：所有物资信息由平台用户手动维护，不对接三方系统

### 5.2 唯一性约束
- **同一存放点下，物资名称不允许重复**
- 新增/编辑时，需校验：同一 storage_id 下，name 字段不允许重复
- 校验失败提示："该存放点下已存在同名物资，请修改名称"

### 5.3 库存更新规则
- **唯一更新入口**：当前库存只能通过盘点操作更新，不支持直接编辑当前库存字段
- **以盘点结果为准**：每次盘点操作直接覆盖当前库存，不自动累加
- **跳过即不更新**：批量盘点、按存放点盘点、导入盘点中，实际数量为空的物资不做任何更新

### 5.4 盘点历史不可删除
- 盘点历史记录一旦生成，不允许用户删除或修改
- 如发生误操作，只能通过再次盘点进行更正（会生成新的盘点记录）
- 物资被删除时，其盘点历史一并物理删除（数据保留意义不大）

### 5.5 库存预警判断逻辑
- 以下条件**同时满足**时，视为库存预警：
  1. 最低库存预警值 ≠ NULL（用户设置了预警值）
  2. 当前库存 ≤ 最低库存预警值
- 库存为零（当前库存 = 0）：无论是否设置预警值，均在"库存状态"筛选中归为"库存为零"
- 筛选逻辑：
  - **库存充足**：已设置预警值 且 当前库存 > 预警值；或未设置预警值（current_stock > 0 且 min_stock_alert IS NULL）
  - **库存预警**：已设置预警值 且 0 < 当前库存 ≤ 预警值
  - **库存为零**：当前库存 = 0

### 5.6 导入盘点的容错处理
- **部分错误不阻断全局**：若导入文件中存在错误行，整个导入请求被拒绝，要求用户修正后重新上传
- **精确匹配**：物资名称 + 存放点名称必须与系统完全一致（区分大小写，不忽略空格）
- **不允许新增**：导入盘点只能更新已存在的物资库存，不会通过导入创建新物资

### 5.7 存放点删除的联动
- 若存放点被删除（理论上不会发生，因为存放点有物资时禁止删除）
- 若因系统异常导致存放点记录丢失，物资台账中的 storage_name 冗余字段仍可显示存放点名称，确保历史数据可读

## 6. 非功能性需求

### 6.1 性能要求
- 列表查询响应时间 < 1秒（2000条数据以内）
- 盘点操作（单条）响应时间 < 500ms
- 批量盘点（50条以内）响应时间 < 2秒
- 导出Excel（含全部盘点历史，10000条以内）响应时间 < 10秒
- 导入盘点（500行以内）响应时间 < 5秒

### 6.2 权限控制
- 有"应急物资管理-物资台账"菜单权限的用户，可进行所有操作（查看、增删改、盘点、导入导出）
- 本期不区分读写权限，有菜单权限 = 有所有操作权限

### 6.3 数据安全
- 删除操作记录操作日志（操作人、操作时间、被删除的物资名称及最后库存）
- 盘点操作记录操作日志（操作人、操作时间、物资名称、盘点前后数量）

### 6.4 兼容性
- 浏览器：Chrome 90+、Edge 90+、Firefox 88+
- 屏幕分辨率：最低支持 1366×768，推荐 1920×1080

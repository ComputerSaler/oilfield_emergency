**文档版本**：V1.0  
**创建日期**：2026-09-14  
**所属模块**：实时监控中心 > 车辆实况  
**页面路由**：`/monitor/vehicle-realtime`

---

## 1. 概述

### 1.1 功能定位
车辆系统实况监控页面，为现场指挥人员提供所有车辆的实时位置、速度和预警信息监控能力。页面采用"地图+双侧边栏"布局，支持实时数据刷新、多维度筛选、快速定位和预警查看。

**车辆监控特点**：
- 无视频功能，仅支持定位
- 车辆类型分为安保用车/生产用车/生活用车三类
- 支持定位后显示极坐标测距网格
- 右侧展示车辆预警信息（SOS/超速等）

### 1.2 核心价值
- 集中展示所有车辆的实时位置和速度
- 快速定位到目标车辆并查看测距范围
- 监控车辆预警事件（SOS/超速）
- 提供详细的车辆信息和预警历史

## 3. 左侧车辆列表面板

### 3.1 KPI统计栏

**展示指标**（基于筛选后的数据）：
- **总数**：当前筛选条件下的车辆总数
- **在线**：`online_status === 'ONLINE'` 的数量，绿色高亮
- **离线**：`online_status === 'OFFLINE'` 的数量，灰色显示

**布局**：3个KPI横向排列，分隔线分隔，居中对齐

### 3.2 筛选器

**筛选维度**：

1. **营地筛选**
   - 类型：单选下拉框
   - 选项：全部 / Jaouro / Koulele / Dibeilla
   - 字段：`camp`（所属营地）

2. **车辆类型筛选**
   - 类型：单选下拉框
   - 选项：全部 / 安保用车 / 生产用车 / 生活用车
   - 字段：`vehicle_type`

**筛选逻辑**：
- 两个筛选条件同时生效（AND关系）
- 筛选后实时更新KPI统计和卡片列表
- 筛选条件不持久化（刷新页面后重置为"全部"）

### 3.3 车辆卡片列表

**卡片布局**：垂直滚动列表，每个卡片包含：

#### 3.3.1 卡片头部
- **左侧**：
  - 车牌号：`plate_number`（例如："NE-00001"）
  - 在线状态指示器：
    - 在线：绿色圆点 + "在线"文字
    - 离线：灰色圆点 + "离线"文字
    - 字段：`online_status`（ONLINE / OFFLINE）

- **右侧**：
  - 车辆类型标签：彩色标签
    - 安保用车：蓝色
    - 生产用车：绿色
    - 生活用车：橙色

#### 3.3.2 车辆信息区
2列横向排列：
- **所属营地**：`camp`
- **当前速度**：`current_speed_kmh` km/h
  - 在线时显示实时速度
  - 离线时显示 "--"

#### 3.3.3 操作按钮区
分隔线之下，1个按钮居中：

**定位按钮**（瞄准图标 `AimOutlined`）：
- **可用条件**：`online_status === 'ONLINE' && telemetry !== null`
- **禁用条件**：`online_status === 'OFFLINE' || telemetry === null`
- **禁用提示**：鼠标悬停显示"离线中不可用"
- **点击行为**：进入定位模式，地图中心定位到该车辆，显示极坐标测距网格

**按钮样式**：
- 正常状态：灰色边框，hover 时蓝色高亮
- 禁用状态：浅灰色，`cursor: not-allowed`，不响应点击
- 尺寸：32px高度

#### 3.3.4 卡片交互
- **点击卡片**：当前无交互（未来可扩展详情弹窗）
- **点击按钮**：事件阻止冒泡，只执行按钮对应操作
- **空状态**：筛选后无数据时，显示空状态提示"暂无车辆数据"

### 3.4 面板收起/展开

- **收起按钮**：面板右边缘中部，小箭头按钮
  - 展开状态：显示左箭头 `LeftOutlined`
  - 收起状态：面板整体向左平移消失
- **触发条**：面板收起后，左侧显示竖向触发条
  - 显示：右箭头 `RightOutlined` + "车辆列表"竖排文字
  - 点击触发条：面板展开
- **联动逻辑**：进入定位模式时，面板自动收起；退出模式时，面板自动展开

## 4. 中央地图区

### 4.1 正常模式

**地图显示**：
- 卫星底图（`VehicleMapView` 组件）
- 车辆POI标记：每辆车一个标记
- **不显示**：预警、事件、人员、无人机、设施等其他实体标记
- **不显示**：左下角图例

**POI标记**：
- 图标：车辆图标（根据车辆类型可能有所区别）
- 位置：`telemetry.latitude`, `telemetry.longitude`（在线车辆有位置数据）
- 状态：
  - 在线：绿色标记
  - 离线：灰色标记
- 点击：当前版本无交互（未来可扩展）

### 4.2 定位模式

**触发方式**：点击车辆卡片的"定位"按钮

**布局变化**：
- **主区域**：地图全屏，中心定位到目标车辆
- **覆盖层**：显示定位标记（车辆位置 + 极坐标测距网格）
- **右上角**：关闭按钮（点击退出定位模式）

**定位标记层级**（从下到上）：

1. **测距范围网格（极坐标）**
   - 4圈同心圆：半径 1.5km、3km、4.5km、6km
   - 12条方位角线：每隔 30° 一条（正北为 0°）
   - 半径标注：在正北方向标注圆圈半径
   - 线条颜色：白色半透明（`rgba(255, 255, 255, 0.4)`）
   - 线宽：1px
   - 文字颜色：白色（`#fff`），黑色描边

2. **中心车辆标记**
   - 车辆图标（根据在线状态显示绿色/灰色）
   - 车牌号标注
   - 白色脉冲动画（扩散到 16px 后消失）

**退出行为**：
- 点击右上角关闭按钮
- 左右面板自动展开
- 地图恢复正常模式，定位标记消失

### 4.3 定位模式的数据来源

**车辆位置数据**：
- 数据源：`focusedVehicle.telemetry`
- 字段：
  - `latitude`：纬度
  - `longitude`：经度
  - `speed_kmh`：速度（km/h）
  - `heading`：行驶方向（度）
  - `last_update`：最后更新时间

## 5. 右侧车辆预警面板

### 5.1 面板结构

**组件**：`VehicleAlertsPanel`

**无Tab切换**：单一列表展示

### 5.2 筛选器

**筛选维度**：

1. **预警类型筛选**
   - 类型：单选下拉框
   - 选项：全部 / SOS / 超速
   - 字段：`alert_type`

2. **时间范围筛选**
   - 类型：单选下拉框
   - 选项：今天 / 最近7天 / 最近30天 / 自定义
   - 自定义：展开日期范围选择器

### 5.3 KPI统计栏

3个指标（基于筛选后的数据）：
- **预警总数**：`filteredAlerts.length`
- **SOS**：`alert_type === 'SOS'` 的数量，红色高亮
- **超速**：`alert_type === '超速'` 的数量，橙色高亮

**布局**：3个KPI横向排列，分隔线分隔，居中对齐

### 5.4 预警卡片列表

每个卡片包含：

**头部**：
- **左侧**：预警类型徽章
  - SOS：红色徽章
  - 超速：橙色徽章
- **右侧**：预警时间，格式化为"YYYY-MM-DD HH:mm:ss"

**信息区**：
- **车牌号**：`plate_number`
- **位置坐标**：`latitude`, `longitude`
  - 格式："纬度°N, 经度°E"（保留4位小数）
- **所属营地**：`camp`
- **车辆类型**：`vehicle_type`

**样式**：
- 卡片背景：`rgba(255, 255, 255, 0.03)`
- 边框：`rgba(255, 255, 255, 0.1)`
- hover 效果：背景变为 `rgba(255, 255, 255, 0.05)`

### 5.5 空状态

筛选后无数据时，显示"暂无预警记录"

### 5.6 面板收起/展开

- **收起按钮**：面板左边缘中部，小箭头按钮
  - 展开状态：显示右箭头 `RightOutlined`
  - 收起状态：面板整体向右平移消失
- **触发条**：面板收起后，右侧显示竖向触发条
  - 显示：左箭头 `LeftOutlined` + "预警列表"竖排文字
  - 点击触发条：面板展开
- **联动逻辑**：进入定位模式时，面板自动收起；退出模式时，面板自动展开

## 7. 数据刷新机制

### 7.1 数据来源
- **通信方式**：WebSocket 实时推送
- **数据源**：航天中台统一数据源

### 7.2 关键字段映射

**车辆数据**（`VehicleRealtimeData`）：
- `vehicle_id`：车辆ID（唯一标识）
- `plate_number`：车牌号
- `vehicle_type`：车辆类型（安保用车 / 生产用车 / 生活用车）
- `camp`：所属营地
- `online_status`：在线状态（ONLINE / OFFLINE）
- `current_speed_kmh`：当前速度（km/h），离线时为 null
- `telemetry`：遥测数据（在线时存在）
  - `latitude`：纬度
  - `longitude`：经度
  - `speed_kmh`：速度（km/h）
  - `heading`：行驶方向（度）
  - `last_update`：最后更新时间（ISO格式）

**预警数据**（`VehicleAlert`）：
- `alert_id`：预警ID（唯一标识）
- `vehicle_id`：车辆ID
- `plate_number`：车牌号
- `alert_type`：预警类型（SOS / 超速）
- `timestamp`：预警时间（ISO格式）
- `latitude`：预警位置纬度
- `longitude`：预警位置经度
- `camp`：所属营地
- `vehicle_type`：车辆类型

### 7.3 刷新策略
- WebSocket 推送：实时更新所有字段
- 前端不做数据缓存，完全依赖推送
- 连接断开时：显示连接状态提示（如需要）

## 8. 交互规则总结

### 8.1 按钮可用性矩阵

| 车辆状态 | 定位按钮 | 提示信息 |
|---------|--------|---------|
| 在线 + 有位置数据 | ✅ 可用 | - |

| 操作 | 左侧面板 | 右侧面板 |
|-----|---------|---------|

| 手动点击收起/展开按钮 | 切换状态 | 不影响 |
| 手动点击收起/展开按钮 | 不影响 | 切换状态 |

### 8.3 空状态处理

| 场景 | 显示内容 |
|-----|---------|
| 左侧列表筛选后无数据 | "暂无车辆数据" |
| 右侧预警列表筛选后无数据 | "暂无预警记录" |

# PRD：反无记录 - 反制记录

**版本**：V1.0  
**日期**：2026-09-14  
**产品**：海外油田应急指挥平台  
**模块**：反无记录 / 反制记录

---

## 1. 文档说明

### 1.1 目的
定义反无人机系统反制记录台账的功能需求，用于记录和查询所有反制操作。

### 1.2 范围
本PRD覆盖反制记录的查询、筛选、展示功能，不包含数据录入（数据来自基础站平台）。

### 1.3 术语
- **基础站**：反无人机设备的数据源系统
- **反制记录**：反制设备执行的反制操作记录
- **反制类型**：手动反制 / 自动反制
- **打击扇区**：反制设备的天线覆盖方向

---

## 2. 业务背景

### 2.1 业务目标
- 记录所有反制操作的执行情况
- 提供操作审计和效果评估能力
- 支持手动/自动反制的统计分析

### 2.2 用户角色
- **安保人员**：查询历史反制记录，评估反制效果
- **管理人员**：统计分析反制操作，评估设备性能和操作规范性

### 2.3 使用场景
1. 查询某日期范围内的反制记录
2. 按反制类型（手动/自动）筛选
3. 查看反制操作的执行状态
4. 统计反制成功率

---

## 3. 功能需求

### 3.1 功能概述
反制记录台账页面，提供查询、筛选、分页展示功能。

### 3.2 数据来源
- **来源系统**：基础站平台（反无设备系统）
- **同步方式**：实时推送 + 历史数据同步
- **数据方向**：单向（只读，不可编辑）

### 3.3 核心功能

#### 3.3.1 数据展示
**表格列定义**：

| 列名 | 字段 | 宽度 | 对齐 | 说明 |
|------|------|------|------|------|
| 记录编号 | id | 180px | 居中 | 唯一标识，支持ellipsis |
| 反制类型 | name | 120px | 居中 | 手动反制/自动反制 |
| 反制设备 | device_name | 140px | 居中 | 设备名称 |
| 反制方式 | jammer_type | 120px | 居中 | 频率干扰/定向干扰/GPS干扰等 |
| 操作人 | operator | 100px | 居中 | 人员姓名或"系统" |
| 反制频段 | Frequency | 140px | 居中 | - |
| 打击扇区 | Direction | 160px | 居中 | 由基础站提供 |
| 持续时间(s) | Duration | 120px | 右对齐 | 数值类型 |
| 执行状态 | status | 100px | 居中 | 成功/失败，颜色标识 |
| 下发指令时间 | issuingInstructionTime | 180px | 居中 | 时间格式 |
| 指令执行时间 | executionTime | 180px | 居中 | 时间格式 |

**表格配置**：
- 分页：支持，每页20条，可切换每页条数
- 排序：暂不支持
- 横向滚动：表格宽度 2100px

#### 3.3.2 搜索筛选
**筛选条件**：

| 筛选项 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| 记录编号 | id | 输入框 | 模糊搜索，忽略大小写 |
| 反制类型 | name | 下拉选择 | 全部类型/手动反制/自动反制 |
| 执行状态 | status | 下拉选择 | 全部状态/成功/失败 |
| 反制设备 | device_name | 输入框 | 模糊搜索，忽略大小写 |
| 创建时间 | dateRange | 日期范围 | 格式 YYYY-MM-DD |

**筛选逻辑**：
- 多条件 AND 关系
- 实时筛选（前端过滤）
- 支持重置按钮（仅在有筛选条件时显示）

#### 3.3.3 统计信息
显示统计栏：
- **总计**：当前筛选结果总数
- **手动反制**：当前筛选结果中手动反制数量
- **自动反制**：当前筛选结果中自动反制数量
- **成功**：当前筛选结果中执行成功数量

#### 3.3.4 数据格式化
- **时间格式**：`YYYY-MM-DD HH:mm:ss`（从ISO时间转换）
- **执行状态**：
  - 值为"是"：绿色徽章 `#52c41a`，显示"成功"
  - 值为"否"：灰色徽章 `#8c8c8c`，显示"失败"
- **打击扇区**：由基础站传入的数值（1-7），自动转换为中文标签显示

## 5. 数据字段定义

### 5.1 反制记录数据结构

```typescript
interface CountermeasureRecord {
  id: string                          // 记录编号
  name: string                        // 反制类型：'手动反制' | '自动反制'
  source: string                      // 来源
  device_id: string                   // 反制设备ID
  device_name: string                 // 反制设备名称
  jammer_type: string                 // 反制方式
  createTime: string                  // 创建时间（ISO格式）
  operator: string                    // 操作人
  record: string                      // 记录附件
  issuingInstructionTime: string      // 下发指令时间（ISO格式）
  executionTime: string               // 指令执行时间（ISO格式）
  Duration: number                    // 持续时间（秒）
  status: string                      // 执行状态：'是' | '否'
  Frequency: string                   // 反制频段
  Direction: number                   // 打击扇区：1-7
}
```

### 5.2 字段说明
- **id**：记录唯一标识，由基础站生成
- **name**：反制类型，值为"手动反制"或"自动反制"
- **source**：记录来源，如"反无系统"、"监控中心"等
- **jammer_type**：反制方式，由基础站提供（如"频率干扰"、"定向干扰"、"GPS干扰"等）
- **operator**：操作人姓名，自动反制时为"系统"
- **Duration**：反制持续时间，单位秒
- **status**：执行状态，"是"表示成功，"否"表示失败
- **Direction**：打击扇区，由基础站提供的数值（1-7），前端转换为中文显示

### 5.3 打击扇区映射
由基础站提供的 `Direction` 数值，前端按以下规则显示：

| Direction 值 | 显示文本 |
|--------------|----------|
| 1 | 右后 |
| 2 | 左后 |
| 3 | 右后、左后 |
| 4 | 前 |
| 5 | 右后、前 |
| 6 | 左后、前 |
| 7 | 右后、左后、前 |

## 6. 交互规范

### 6.1 表格交互
- 长文本（记录编号）：鼠标悬停显示完整内容（Tooltip）
- 分页：支持跳转到指定页、切换每页条数、显示总数

### 6.2 筛选交互
- 输入框：支持清除按钮
- 日期范围：支持快捷选择（今天、近7天、近30天）
- 重置按钮：清空所有筛选条件，回到第1页

### 6.3 视觉反馈
- 执行状态徽章：成功=绿色，失败=灰色
- 统计栏：高亮显示数值，便于快速识别

## 8. 架构决策

### 8.1 设计决策
1. **只读台账**：数据来自基础站，平台不提供新建/编辑/删除功能
2. **前端分页**：数据量可控，使用前端分页提升响应速度
3. **实时筛选**：筛选在前端执行，无需请求后端
4. **颜色标识**：使用徽章样式区分执行状态（成功=绿色，失败=灰色）
5. **打击扇区映射**：前端根据 Direction 数值自动转换为中文标签

### 8.2 数据规范
- **时间格式**：统一使用 `YYYY-MM-DD HH:mm:ss`
- **表格对齐**：文字居中、数字右对齐
- **长标识符列**：加宽 + CSS ellipsis + Tooltip
- **执行状态映射**："是" → "成功"，"否" → "失败"

### 8.3 UI规范
- 使用 `PageContainer + PanelCard` 结构
- 状态徽章：`padding: 2px 8px; border-radius: 10px; font-size: 12px`
- 统计栏：背景色 `var(--of-fill-quaternary)`
- 执行状态颜色：成功=绿色 `#52c41a`，失败=灰色 `#8c8c8c`

# PRD：反无记录 - 入侵记录

**版本**：V1.0  
**日期**：2026-09-14  
**产品**：海外油田应急指挥平台  
**模块**：反无记录 / 入侵记录

---

## 1. 文档说明

### 1.1 目的
定义反无人机系统入侵记录台账的功能需求，用于记录和查询所有入侵事件。

### 1.2 范围
本PRD覆盖入侵记录的查询、筛选、展示功能，不包含数据录入（数据来自基础站平台）。

### 1.3 术语
- **基础站**：反无人机设备的数据源系统
- **入侵记录**：进入预警区或反制区的无人机事件
- **入侵等级**：由基础站判定的威胁等级（1-3级）

---

## 2. 业务背景

### 2.1 业务目标
- 记录所有进入预警区/反制区的入侵事件
- 按入侵等级分类管理，便于威胁评估
- 提供历史查询和统计分析能力

### 2.2 用户角色
- **安保人员**：查询历史入侵记录，评估威胁态势
- **管理人员**：统计分析入侵事件，评估防护效果

### 2.3 使用场景
1. 查询某日期范围内的入侵记录
2. 按入侵等级筛选高危事件
3. 统计各等级入侵事件数量
4. 分析入侵无人机的飞行参数（高度、速度、距离等）

---

## 3. 功能需求

### 3.1 功能概述
入侵记录台账页面，提供查询、筛选、分页展示功能。

### 3.2 数据来源
- **来源系统**：基础站平台（反无设备系统）
- **同步方式**：实时推送 + 历史数据同步
- **数据方向**：单向（只读，不可编辑）

### 3.3 核心功能

#### 3.3.1 数据展示
**表格列定义**：

| 列名 | 字段 | 宽度 | 对齐 | 说明 |
|------|------|------|------|------|
| ID | id | 180px | 居中 | 唯一标识，支持ellipsis |
| 序列号 | Uavid | 160px | 居中 | 无人机序列号，支持ellipsis |
| 无人机名称 | uav_name | 150px | 居中 | - |
| 无人机型号 | uav_model | 180px | 居中 | - |
| 入侵等级 | AlarmLevel | 100px | 居中 | 1-3级，颜色标识 |
| 高度(m) | height | 100px | 右对齐 | 数值类型 |
| 速度(m/s) | velocity | 110px | 右对齐 | 数值类型 |
| 方位角(°) | azimuth | 110px | 右对齐 | 数值类型 |
| 距离(m) | distance | 100px | 右对齐 | 数值类型 |
| 频率 | Frequency | 100px | 居中 | - |
| 是否白名单 | isWhiteList | 120px | 居中 | 值：'是' / '否' |
| 持续时间(s) | Duration | 120px | 右对齐 | 数值类型 |
| 发现开始日期 | StartFrom | 140px | 居中 | 日期格式 |

**表格配置**：
- 分页：支持，每页20条，可切换每页条数
- 排序：暂不支持
- 横向滚动：表格宽度 2000px

#### 3.3.2 搜索筛选
**筛选条件**：

| 筛选项 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| 序列号 | Uavid | 输入框 | 模糊搜索，忽略大小写 |
| 入侵等级 | AlarmLevel | 下拉选择 | 全部等级/1级/2级/3级 |
| 是否白名单 | isWhiteList | 下拉选择 | 全部/是/否 |
| 无人机型号 | uav_model | 输入框 | 模糊搜索，忽略大小写 |
| 发现时间 | dateRange | 日期范围 | 格式 YYYY-MM-DD |

**筛选逻辑**：
- 多条件 AND 关系
- 实时筛选（前端过滤）
- 支持重置按钮（仅在有筛选条件时显示）

#### 3.3.3 统计信息
显示统计栏：
- **总计**：当前筛选结果总数
- **1级**：当前筛选结果中1级入侵数量
- **2级**：当前筛选结果中2级入侵数量
- **3级**：当前筛选结果中3级入侵数量

#### 3.3.4 数据格式化
- **日期格式**：`YYYY-MM-DD`
- **入侵等级**：
  - 1级：绿色徽章 `#52c41a`，显示"1级"
  - 2级：黄色徽章 `#faad14`，显示"2级"
  - 3级：红色徽章 `#ff4d4f`，显示"3级"
- **是否白名单**：
  - 值为"是"：绿色徽章 `#52c41a`
  - 值为"否"：灰色徽章 `#8c8c8c`

## 5. 数据字段定义

### 5.1 入侵记录数据结构

```typescript
interface IntrusionRecord {
  id: string                  // ID
  Uavid: string              // 序列号
  uav_name: string           // 无人机名称
  Traceid: string            // 轨迹ID
  uav_model: string          // 无人机型号
  height: number             // 高度（米）
  velocity: number           // 速度（m/s）
  azimuth: number            // 方位角（度）
  distance: number           // 距离（米）
  yaw: number                // 水平角度（度）
  Frequency: string          // 频率
  StartFrom: string          // 发现开始日期
  StartTime: string          // 发现开始时间
  connectTime: string        // 发现结束时间（ISO格式）
  isWhiteList: string        // 是否白名单：'是' | '否'
  AlarmLevel: number         // 入侵等级：1-3
  Duration: number           // 持续时间（秒）
}
```

### 5.2 字段说明
- **id**：记录唯一标识，由基础站生成
- **Uavid**：无人机序列号
- **Traceid**：轨迹标识
- **AlarmLevel**：入侵等级，由基础站判定（1-3级，数值越大威胁越高）
- **height**：无人机飞行高度，单位米
- **velocity**：无人机飞行速度，单位 m/s
- **azimuth**：相对于侦测设备的方位角，单位度
- **distance**：相对于侦测设备的距离，单位米
- **yaw**：水平角度，由基础站提供
- **Duration**：从发现开始到结束的持续时间，单位秒

## 6. 交互规范

### 6.1 表格交互
- 长文本（ID、序列号）：鼠标悬停显示完整内容（Tooltip）
- 分页：支持跳转到指定页、切换每页条数、显示总数

### 6.2 筛选交互
- 输入框：支持清除按钮
- 日期范围：支持快捷选择（今天、近7天、近30天）
- 重置按钮：清空所有筛选条件，回到第1页

### 6.3 视觉反馈
- 入侵等级徽章：醒目的颜色标识（绿/黄/红）
- 统计栏：高亮显示数值，便于快速识别

## 8. 架构决策

### 8.1 设计决策
1. **只读台账**：数据来自基础站，平台不提供新建/编辑/删除功能
2. **前端分页**：数据量可控，使用前端分页提升响应速度
3. **实时筛选**：筛选在前端执行，无需请求后端
4. **颜色标识**：使用三级颜色（绿/黄/红）区分入侵等级

### 8.2 数据规范
- **日期格式**：统一使用 `YYYY-MM-DD`
- **表格对齐**：文字居中、数字右对齐
- **长标识符列**：加宽 + CSS ellipsis + Tooltip

### 8.3 UI规范
- 使用 `PageContainer + PanelCard` 结构
- 状态徽章：`padding: 2px 8px; border-radius: 10px; font-size: 12px`
- 统计栏：背景色 `var(--of-fill-quaternary)`
- 入侵等级颜色：1级绿色、2级黄色、3级红色

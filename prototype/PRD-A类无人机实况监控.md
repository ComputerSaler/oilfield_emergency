# PRD：A类无人机实况监控

**文档版本**：V1.0  
**创建日期**：2026-09-01  
**所属模块**：实时监控中心 > A类无人机实况  
**页面路由**：`/monitor/a-uav-realtime`

---

## 1. 概述

### 1.1 功能定位
A类无人机实况监控页面，为现场指挥人员提供所有A类无人机的实时状态监控、快速定位和视频流查看能力。页面采用"地图+侧边栏"布局，支持实时数据刷新、状态筛选、快速操作和详情查看。

### 1.2 核心价值
- 集中展示所有A类无人机的实时状态和位置
- 快速定位到目标无人机并查看实时视频流
- 支持多维度筛选和KPI统计
- 提供详细的飞行数据和历史记录查询

## 3. 左侧无人机列表面板

### 3.1 KPI统计栏

**展示指标**（基于筛选后的数据）：
- **总数**：当前筛选条件下的无人机总数
- **在线**：`online_status === 'ONLINE'` 的数量，绿色高亮
- **飞行中**：`realtime_status === '飞行中'` 的数量，蓝色高亮
- **离线**：`online_status === 'OFFLINE'` 的数量，灰色显示

**布局**：4个KPI横向排列，分隔线分隔，居中对齐

### 3.2 筛选器

**筛选维度**：

1. **营地筛选**
   - 类型：单选下拉框
   - 选项：全部 / Jaouro营地 / Koulele营地 / Dibeilla营地
   - 字段：`ground_station_name`（模糊匹配营地名称）

2. **飞行状态筛选**
   - 类型：单选下拉框
   - 选项：全部 / 飞行中 / 未飞行
   - 字段：`realtime_status`

**筛选逻辑**：
- 两个筛选条件同时生效（AND关系）
- 筛选后实时更新KPI统计和卡片列表
- 筛选条件不持久化（刷新页面后重置为"全部"）

### 3.3 无人机卡片列表

**卡片布局**：垂直滚动列表，每个卡片包含：

#### 3.3.1 卡片头部
- **左侧**：
  - 无人机名称：`aircraft_name`，若为空则显示 `drone_sn`
  - 在线状态指示器：
    - 在线：绿色圆点 + "在线"文字
    - 离线：灰色圆点 + "离线"文字
    - 字段：`online_status`（ONLINE / OFFLINE）

- **右侧**：
  - 飞行状态徽章：圆角矩形，背景色根据 `realtime_status` 映射
    - 飞行中：`#52c41a`（绿色）
    - 未飞行：`#1481a6`（蓝色）

#### 3.3.2 累计统计区
3列横向排列：
- **总里程**：`total_flight_distance_m`，单位转换为 km，保留1位小数
- **总航时**：`total_flight_duration_sec`，转换为"X小时Y分"格式
- **总架次**：`total_sorties`，整数

#### 3.3.3 今日统计区
分隔线之下，3列横向排列：
- **今日里程**：`today_stats.today_distance_m`，单位转换为 km
- **今日航时**：`today_stats.today_duration_sec`，转换为"X小时Y分"
- **今日架次**：`today_stats.today_sorties`，整数

#### 3.3.4 操作按钮区
分隔线之下，2个按钮横向排列，等宽：

**定位按钮**（瞄准图标 `AimOutlined`）：
- **可用条件**：`online_status === 'ONLINE'`
- **禁用条件**：`online_status === 'OFFLINE'`
- **禁用提示**：鼠标悬停显示"离线中不可用"
- **点击行为**：进入地图模式，定位到该无人机

**视频按钮**（摄像机图标 `VideoCameraOutlined`）：
- **可用条件**：`online_status === 'ONLINE' && realtime_status === '飞行中'`
- **禁用条件**：
  - `online_status === 'OFFLINE'`：显示"离线中不可用"
  - `realtime_status === '未飞行'`：显示"未飞行，无实时视频流"
- **点击行为**：进入视频流模式，查看该无人机的实时视频

**按钮样式**：
- 正常状态：灰色边框，hover 时蓝色高亮
- 禁用状态：浅灰色，`cursor: not-allowed`，不响应点击
- 尺寸：32px高度，等宽平分

#### 3.3.5 卡片交互
- **点击卡片**：打开详情弹窗（点击操作按钮不触发）
- **点击按钮**：事件阻止冒泡，只执行按钮对应操作
- **空状态**：筛选后无数据时，显示空状态提示"暂无无人机数据"

### 3.4 面板收起/展开

- **收起按钮**：面板右边缘中部，小箭头按钮
  - 展开状态：显示左箭头 `LeftOutlined`
  - 收起状态：面板整体向左平移消失
- **触发条**：面板收起后，左侧显示竖向触发条
  - 显示：右箭头 `RightOutlined` + "无人机列表"竖排文字
  - 点击触发条：面板展开
- **联动逻辑**：进入视频/地图模式时，面板自动收起；退出模式时，面板自动展开

## 4. 中央地图区

### 4.1 正常模式

**地图显示**：
- 卫星底图（复用 `MapSimulator` 组件）
- A类无人机POI标记：根据 `drone_sn` 映射到地图坐标
- **不显示**：预警、事件、人员、车辆、设施等其他实体标记
- **不显示**：左下角图例

**POI标记**：
- 图标：A类无人机图标
- 位置：根据 `drone_sn` 查找预设坐标映射表
- 点击：当前版本无交互（未来可扩展）

### 4.2 视频流模式

**触发方式**：点击无人机卡片的"视频"按钮

**布局变化**：
- **主区域**：实时视频流（占据大部分空间）
- **右下角**：地图缩略图（约 1/4 屏幕）
- **底部**：飞行参数条（显示实时遥测数据）
- **右上角**：关闭按钮（点击退出视频模式）

**飞行参数**（来自 `telemetry` 对象）：
- 起飞时间、飞行时长、剩余距离、实时经纬度
- 飞行高度、地速、垂直速度、当前电量

**退出行为**：
- 点击右上角关闭按钮
- 左右面板自动展开
- 地图恢复正常模式

### 4.3 地图模式

**触发方式**：点击无人机卡片的"定位"按钮

**布局变化**：
- **主区域**：地图（占据大部分空间），中心定位到目标无人机
- **右下角**：视频缩略图（约 1/4 屏幕）
- **右上角**：关闭按钮

**极坐标测距网格**：
- **显示规则**：以目标无人机为中心，显示极坐标测距网格
- **网格结构**：
  - 4圈同心圆：半径分别为 1.5km、3km、4.5km、6km
  - 12条方位角线：每隔 30° 一条（正北为 0°）
  - 半径标注：在正北方向标注圆圈半径（1.5km、3km、4.5km、6km）
- **视觉样式**：
  - 线条颜色：白色半透明（`rgba(255, 255, 255, 0.4)`）
  - 线宽：1px
  - 文字颜色：白色（`#fff`），黑色描边
- **用途**：快速估算无人机与目标位置的距离和方位

**退出行为**：同视频流模式

### 4.4 模式切换约束

- **不可切换无人机**：进入视频/地图模式后，锁定在当前无人机，不支持切换到其他无人机
- **退出方式**：只能通过点击右上角关闭按钮退出
- **面板联动**：
  - 进入任一模式：左右面板自动收起
  - 退出模式：左右面板自动展开
  - 手动收起的面板状态不影响联动

## 7. 数据刷新机制

### 7.1 数据来源
- **通信方式**：WebSocket 实时推送
- **数据源**：航天中台统一数据源

### 7.2 关键字段映射

**无人机主数据**：
- `drone_sn`：设备序列号（唯一标识）
- `aircraft_name`：无人机名称
- `online_status`：在线状态（ONLINE / OFFLINE）
- `realtime_status`：飞行状态（飞行中 / 未飞行）
- `ground_station_name`：当前地面站名称
- `total_flight_distance_m`：总飞行距离（米）
- `total_flight_duration_sec`：总飞行时长（秒）
- `total_sorties`：总飞行架次

**今日统计**（`today_stats` 对象）：
- `today_distance_m`：今日里程（米）
- `today_duration_sec`：今日航时（秒）
- `today_sorties`：今日架次

**实时遥测**（`telemetry` 对象，仅飞行中有值）：
- `takeoff_time`：起飞时间（ISO 8601）
- `flight_duration_sec`：飞行时长（秒）
- `remaining_distance_m`：剩余距离（米）
- `longitude`：实时经度
- `latitude`：实时纬度
- `altitude_m`：飞行高度（米）
- `ground_speed_ms`：地速（m/s）
- `vertical_speed_ms`：垂直速度（m/s）
- `battery_percent`：当前电量（百分比 0-100）

### 7.3 刷新策略
- WebSocket 推送：实时更新所有字段
- 前端不做数据缓存，完全依赖推送
- 连接断开时：显示连接状态提示（如需要）

## 8. 交互规则总结

### 8.1 按钮可用性矩阵

| 无人机状态 | 定位按钮 | 视频按钮 | 提示信息 |
|---------|--------|--------|---------|
| 在线 + 飞行中 | ✅ 可用 | ✅ 可用 | - |
| 在线 + 未飞行 | ✅ 可用 | ❌ 禁用 | "未飞行，无实时视频流" |
| 离线 | ❌ 禁用 | ❌ 禁用 | "离线中不可用" |

### 8.2 面板联动规则

| 操作 | 左侧面板 | 右侧面板 |
|-----|---------|---------|
| 点击"定位"按钮 | 自动收起 | 自动收起 |
| 点击"视频"按钮 | 自动收起 | 自动收起 |
| 点击关闭按钮退出模式 | 自动展开 | 自动展开 |
| 手动点击收起/展开按钮 | 切换状态 | 不影响 |
| 手动点击收起/展开按钮 | 不影响 | 切换状态 |

**优先级**：视频/地图模式的联动 > 用户手动操作

### 8.3 空状态处理

| 场景 | 显示内容 |
|-----|---------|
| 左侧列表筛选后无数据 | "暂无无人机数据" |
| 飞行记录筛选后无数据 | "暂无飞行记录" |
| 事件列表筛选后无数据 | "暂无事件记录" |
| 详情弹窗-飞行实况无数据 | "当前无飞行实况数据" |

# PRD：反无记录 - 探测记录

**版本**：V1.0  
**日期**：2026-09-14  
**产品**：海外油田应急指挥平台  
**模块**：反无记录 / 探测记录

---

## 1. 文档说明

### 1.1 目的
定义反无人机系统探测记录台账的功能需求，用于记录和查询所有无人机侦测架次。

### 1.2 范围
本PRD覆盖探测记录的查询、筛选、展示功能，不包含数据录入（数据来自基础站平台）。

### 1.3 术语
- **基础站**：反无人机设备的数据源系统
- **探测记录**：反无系统侦测到的无人机架次记录
- **白名单**：己方授权无人机清单

---

## 2. 业务背景

### 2.1 业务目标
- 记录所有反无系统侦测到的无人机架次
- 提供历史查询和统计分析能力
- 支持白名单识别和筛选

### 2.2 用户角色
- **安保人员**：查询历史探测记录，分析无人机活动规律
- **管理人员**：统计分析，评估反无系统工作状态

### 2.3 使用场景
1. 查询某日期范围内的探测记录
2. 筛选特定设备的探测记录
3. 识别白名单/非白名单无人机
4. 统计探测记录总数和白名单数量

---

## 3. 功能需求

### 3.1 功能概述
探测记录台账页面，提供查询、筛选、分页展示功能。

### 3.2 数据来源
- **来源系统**：基础站平台（反无设备系统）
- **同步方式**：实时推送 + 历史数据同步
- **数据方向**：单向（只读，不可编辑）

### 3.3 核心功能

#### 3.3.1 数据展示
**表格列定义**：

| 列名 | 字段 | 宽度 | 对齐 | 说明 |
|------|------|------|------|------|
| 记录ID | id | 180px | 居中 | 唯一标识，支持ellipsis |
| 序列号 | uav_id | 160px | 居中 | 无人机序列号，支持ellipsis |
| 无人机名称 | uav_name | 150px | 居中 | - |
| 无人机型号 | uav_model | 180px | 居中 | - |
| 轨迹ID | trace_id | 180px | 居中 | 支持ellipsis |
| 侦测设备 | device_name | 140px | 居中 | 侦测设备名称 |
| 频率(GHz) | frequency | 120px | 右对齐 | 数值类型 |
| 持续时间(s) | duration | 120px | 右对齐 | 数值类型 |
| 是否白名单 | isWhiteList | 120px | 居中 | 值：'是' / '否' |
| 侦测开始 | start_time | 180px | 居中 | 时间格式 |
| 创建时间 | createTime | 180px | 居中 | 时间格式 |

**表格配置**：
- 分页：支持，每页20条，可切换每页条数
- 排序：暂不支持
- 横向滚动：表格宽度 1800px

#### 3.3.2 搜索筛选
**筛选条件**：

| 筛选项 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| 序列号 | uav_id | 输入框 | 模糊搜索，忽略大小写 |
| 是否白名单 | isWhiteList | 下拉选择 | 全部/是/否 |
| 侦测设备 | device_name | 输入框 | 模糊搜索，忽略大小写 |
| 创建时间 | dateRange | 日期范围 | 格式 YYYY-MM-DD |

**筛选逻辑**：
- 多条件 AND 关系
- 实时筛选（前端过滤）
- 支持重置按钮（仅在有筛选条件时显示）

#### 3.3.3 统计信息
显示统计栏：
- **总计**：当前筛选结果总数
- **白名单**：当前筛选结果中白名单数量

#### 3.3.4 数据格式化
- **时间格式**：`YYYY-MM-DD HH:mm:ss`（从ISO时间转换）
- **是否白名单**：
  - 值为"是"：绿色徽章 `#52c41a`
  - 值为"否"：灰色徽章 `#8c8c8c`

## 5. 数据字段定义

### 5.1 探测记录数据结构

```typescript
interface DetectionRecord {
  id: string                  // 记录ID
  uav_id: string             // 序列号
  uav_name: string           // 无人机名称
  longitude: number          // 经度
  trace_id: string           // 轨迹ID
  latitude: number           // 纬度
  frequency: number          // 频率
  connectTime: string        // 侦测结束时间（ISO格式）
  start_time: string         // 侦测开始时间（ISO格式）
  device_id: string          // 侦测设备ID
  device_name: string        // 侦测设备名称
  uav_model: string          // 无人机型号
  isWhiteList: string        // 是否白名单：'是' | '否'
  duration: number           // 持续时间（秒）
  createTime: string         // 创建时间（ISO格式）
}
```

### 5.2 字段说明
- **id**：记录唯一标识，由基础站生成
- **uav_id**：无人机序列号（如MAC地址、设备SN等）
- **trace_id**：轨迹标识，用于关联同一架无人机的多次探测
- **frequency**：工作频率，单位GHz
- **duration**：从侦测开始到结束的持续时间，单位秒
- **isWhiteList**：由基础站判定，'是'表示在白名单中

## 8. 架构决策

### 8.1 设计决策
1. **只读台账**：数据来自基础站，平台不提供新建/编辑/删除功能
2. **前端分页**：数据量可控，使用前端分页提升响应速度
3. **实时筛选**：筛选在前端执行，无需请求后端
4. **颜色标识**：使用徽章样式区分白名单状态

### 8.2 数据规范
- **时间格式**：统一使用 `YYYY-MM-DD HH:mm:ss`
- **表格对齐**：文字居中、数字右对齐
- **长标识符列**：加宽 + CSS ellipsis + Tooltip

### 8.3 UI规范
- 使用 `PageContainer + PanelCard` 结构
- 状态徽章：`padding: 2px 8px; border-radius: 10px; font-size: 12px`
- 统计栏：背景色 `var(--of-fill-quaternary)`

# PRD：反无系统实况监控

**文档版本**：V1.0  
**创建日期**：2026-09-14  
**所属模块**：实时监控中心 > 反无系统实况  
**页面路由**：`/monitor/counter-uas-realtime`

---

## 1. 概述

### 1.1 功能定位
反无系统实况监控页面，为现场指挥人员提供所有反无人机系统的实时状态监控、探测目标追踪和系统定位能力。页面采用"地图+双侧边栏"布局，按营地聚合展示反无系统状态，支持实时数据刷新、状态筛选和详情查看。

**反无系统特点**：
- 按营地聚合展示（每个营地包含多个侦测/反制设备）
- 系统状态分为探测中/打击中/离线三级
- 支持定位后显示测距网格、预警区、反制区、设备图标和探测到的无人机

### 1.2 核心价值
- 集中展示所有营地的反无系统状态和探测目标数量
- 快速定位到目标营地并查看测距范围和设备分布
- 监控反制设备的打击状态和打击参数
- 提供详细的设备列表和今日统计数据

## 3. 左侧系统列表面板

### 3.1 KPI统计栏

**展示指标**（基于筛选后的数据）：
- **总数**：当前筛选条件下的营地系统总数
- **探测中**：`status === 'detecting' || status === 'striking'` 的数量，绿色高亮
- **打击中**：`status === 'striking'` 的数量，红色高亮
- **离线**：`status === 'offline'` 的数量，灰色显示

**布局**：4个KPI横向排列，分隔线分隔，居中对齐

### 3.2 筛选器

**筛选维度**：

1. **营地筛选**
   - 类型：单选下拉框
   - 选项：全部 / Jaouro / Koulele / Dibeilla
   - 字段：`camp`（营地名称）

2. **状态筛选**
   - 类型：单选下拉框
   - 选项：全部 / 探测中 / 打击中 / 离线
   - 字段：`status`（系统状态）

**筛选逻辑**：
- 两个筛选条件同时生效（AND关系）
- 筛选后实时更新KPI统计和卡片列表
- 筛选条件不持久化（刷新页面后重置为"全部"）

### 3.3 系统卡片列表

**数据聚合规则**：
- 按营地分组，每个营地生成一个系统卡片
- 系统状态优先级：打击中 > 探测中 > 离线
  - 营地下任一设备为"打击中" → 系统状态为"打击中"
  - 营地下任一设备为"探测中"且无"打击中" → 系统状态为"探测中"
  - 营地下所有设备均为"离线" → 系统状态为"离线"
- 探测目标总数 = 营地下所有设备的 `current_targets` 之和
- 今日统计 = 营地下所有设备的今日统计累加

**卡片布局**：垂直滚动列表，每个卡片包含：

#### 3.3.1 卡片头部
- **左侧**：
  - 营地名称：`camp`
  - "反无系统"标签

- **右侧**：
  - 系统状态徽章：圆角矩形，背景色根据 `status` 映射
    - 探测中：`#52c41a`（绿色）
    - 打击中：`#ff4d4f`（红色）
    - 离线：`rgba(255, 255, 255, 0.25)`（灰色）

#### 3.3.2 探测目标区
- **当前探测目标**：`current_targets` 个，大号数字，高亮显示
- 若 > 0，显示橙色高亮

#### 3.3.3 今日统计区
3列横向排列：
- **今日探测**：`today_detection_count` 次
- **今日预警**：`today_warning_count` 次
- **今日入侵**：`today_intrusion_count` 次

#### 3.3.4 反制设备状态区
- **打击中的反制设备**：`striking_devices`
  - 格式：设备名（方式）、设备名（方式）
  - 示例："东南角反制（自动）、西北角反制（手动）"
  - 若无打击中设备，显示 "-"

#### 3.3.5 操作按钮区
分隔线之下，1个按钮居中：

**定位按钮**（瞄准图标 `AimOutlined`）：
- **点击行为**：进入定位模式，地图中心定位到该营地系统，显示测距网格、预警区、反制区、设备图标、探测到的无人机

#### 3.3.6 卡片交互
- **点击卡片**：打开详情弹窗（点击操作按钮不触发）
- **点击按钮**：事件阻止冒泡，只执行按钮对应操作
- **空状态**：筛选后无数据时，显示空状态提示"暂无系统数据"

### 3.4 面板收起/展开

- **收起按钮**：面板右边缘中部，小箭头按钮
  - 展开状态：显示左箭头 `LeftOutlined`
  - 收起状态：面板整体向左平移消失
- **触发条**：面板收起后，左侧显示竖向触发条
  - 显示：右箭头 `RightOutlined` + "反无系统"竖排文字
  - 点击触发条：面板展开
- **联动逻辑**：进入定位模式时，左右面板自动收起；退出模式时，面板自动展开

## 4. 中央地图区

### 4.1 正常模式

**地图显示**：
- 卫星底图（复用 `MapSimulator` 组件）
- 反无系统POI标记：每个营地一个标记
- **不显示**：预警、事件、人员、车辆、设施等其他实体标记
- **不显示**：左下角图例

**POI标记**：
- 图标：雷达图标 `RadarChartOutlined`
- 位置：使用该营地下第一个设备的经纬度
- 点击：当前版本无交互（未来可扩展）

### 4.2 定位模式

**触发方式**：点击系统卡片的"定位"按钮

**布局变化**：
- **主区域**：地图全屏，中心定位到目标营地系统
- **覆盖层**：显示定位标记（测距网格、预警区、反制区、设备图标、探测到的无人机）
- **右上角**：关闭按钮（点击退出定位模式）

**定位标记层级**（从下到上）：

1. **测距范围网格（极坐标）**
   - 4圈同心圆：半径 1.5km、3km、4.5km、6km
   - 12条方位角线：每隔 30° 一条（正北为 0°）
   - 半径标注：在正北方向标注圆圈半径
   - 线条颜色：白色半透明（`rgba(255, 255, 255, 0.3)`）
   - 线宽：1px
   - 文字颜色：白色（`#fff`），黑色描边

2. **预警区域（黄色圆圈）**
   - 半径：3km
   - 填充：`rgba(255, 193, 7, 0.15)`（黄色半透明）
   - 边框：`rgba(255, 193, 7, 0.6)`（黄色）
   - 边框宽度：2px
   - 边框样式：虚线（`stroke-dasharray: 8 4`）

3. **反制区域（红色圆圈）**
   - 半径：1.5km
   - 填充：`rgba(255, 77, 79, 0.2)`（红色半透明）
   - 边框：`rgba(255, 77, 79, 0.8)`（红色）
   - 边框宽度：2px
   - 边框样式：虚线（`stroke-dasharray: 8 4`）

4. **中心点标记**
   - 白色圆点，半径 8px
   - 白色脉冲动画（扩散到 16px 后消失）

5. **设备图标**
   - 在中心点周围圆形均匀分布（半径 100px）
   - 图标：雷达图标（侦测设备）或闪电图标（反制设备）
   - 颜色：根据设备状态
     - 探测中/打击中：绿色/红色
     - 离线：灰色
   - 每个图标下方显示设备名称
   - 图标尺寸：24px
   - 图标位置计算：角度 = (index / total) × 360°

6. **探测到的无人机标记**
   - 图标：无人机图标，橙色
   - 位置：根据无人机的方位角和距离计算屏幕坐标
   - 标注：显示无人机的方位角和距离（例如："45°-2.3km"）
   - 脉冲动画：橙色脉冲圈
   - 尺寸：24px

**退出行为**：
- 点击右上角关闭按钮
- 左右面板自动展开
- 地图恢复正常模式，定位标记消失

### 4.3 定位模式的数据来源

**探测到的无人机数据**：
- 数据源：`DETECTED_DRONES_DATA`（来自 `@/mock/detectedDrones`）
- 筛选规则：`reporting_system === 当前定位的营地系统名称`
- 字段：
  - `reporting_system`：上报系统（营地名称）
  - `target_id`：目标ID
  - `detection_time`：探测时间
  - `azimuth`：方位角（度）
  - `distance`：距离（米）
  - `lat`、`lng`：经纬度

**右侧探测到的无人机面板联动**：
- 进入定位模式时，右侧面板的筛选器自动切换到当前营地
- 显示该营地探测到的所有无人机

#### 6.2.2 设备列表（表格）

**表格列定义**：

| 列名 | 字段 | 宽度 | 对齐方式 | 说明 |

- 显示逻辑：

  - 格式：数值 + "s"（例如："30s"）
  - 若该设备无此字段，显示 "-"
- **非反制设备**：显示 "-"

**反制功率字段说明**：
- 字段名：`strike_power`
- 类型：数值（百分比 0-100）
- 显示逻辑：
  - 仅当 `device_type === 'counteract'` 时显示
  - 格式：数值 + "%"（例如："85%"）
  - 若该设备无此字段，显示 "-"
- **非反制设备**：显示 "-"

## 7. 数据刷新机制

### 7.1 数据来源
- **通信方式**：WebSocket 实时推送
- **数据源**：航天中台统一数据源

### 7.2 关键字段映射

**设备数据**（`CounterUasDevice`）：
- `id`：设备ID（唯一标识）
- `name`：设备名称
- `device_type`：设备类型（detect / counteract）
- `status`：设备状态（detecting / striking / offline）
- `current_targets`：当前探测到的目标数量
- `camp`：所属营地
- `model`：型号
- `latitude`、`longitude`：经纬度
- `frequency`：工作频率
- `gps_satellites`：GPS卫星数
- `temperature`：温度（℃）
- `calibration_angle`：校准角度（度）
- `today_detection_count`：当日探测次数
- `today_warning_count`：当日预警次数
- `today_intrusion_count`：当日入侵次数
- `counteract_mode`：反制方式（auto / manual），仅反制设备有
- `strike_mode`：打击模式（['expel', 'force_land']），仅反制设备有
- `strike_duration`：持续时间（秒），仅反制设备有
- `strike_power`：反制功率（百分比 0-100），仅反制设备有
- `last_communication_time`：最后通信时间（ISO格式）

**探测到的无人机数据**（`DetectedDrone`）：
- `target_id`：目标ID
- `reporting_system`：上报系统（营地名称）
- `detection_time`：探测时间（ISO格式）
- `azimuth`：方位角（度）
- `distance`：距离（米）
- `lat`、`lng`：经纬度
- `altitude`：高度（米）
- `speed`：速度（m/s）

### 7.3 刷新策略
- WebSocket 推送：实时更新所有字段
- 前端不做数据缓存，完全依赖推送
- 探测到的无人机持续时长：前端每秒计算一次
- 连接断开时：显示连接状态提示（如需要）

## 8. 交互规则总结

### 8.1 系统状态优先级

| 营地下设备状态 | 系统状态 |
|-------------|---------|
| 任一设备为"打击中" | 打击中 |
| 任一设备为"探测中"且无"打击中" | 探测中 |
| 所有设备均为"离线" | 离线 |

### 8.2 面板联动规则

| 操作 | 左侧面板 | 右侧面板 | 右侧筛选器 |
|-----|---------|---------|-----------|
| 点击"定位"按钮 | 自动收起 | 自动收起 | 自动切换到对应营地 |
| 点击关闭按钮退出定位 | 自动展开 | 自动展开 | 保持筛选状态 |
| 手动点击收起/展开按钮 | 切换状态 | 不影响 | - |
| 手动点击收起/展开按钮 | 不影响 | 切换状态 | - |

### 8.3 空状态处理

| 场景 | 显示内容 |
|-----|---------|
| 左侧列表筛选后无数据 | "暂无系统数据" |
| 右侧探测列表筛选后无数据 | "暂无探测到的无人机" |

## 9. 非功能需求

### 9.1 性能要求
- 列表渲染：支持10+营地系统卡片流畅滚动

- 持续时长实时更新：每秒刷新，无卡顿

### 9.2 兼容性
- 浏览器：Chrome 90+, Edge 90+
- 分辨率：1920x1080 及以上

### 9.3 可访问性
- 定位模式的测距网格、预警区、反制区使用颜色+虚线双编码
- 设备状态使用颜色+文字双编码
